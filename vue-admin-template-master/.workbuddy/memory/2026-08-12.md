# 2026-08-12 工作日志

## 前端模板对接后端用户接口

将 vue-admin-template 前端从 mock 模式改为对接 Spring Boot 后端的真实 API。

### 改动文件清单
1. **vue.config.js** — 移除 mock-server 中间件，添加 devServer.proxy 将 `/dev-api` 转发到 `http://localhost:8080`，pathRewrite 去掉 `/dev-api` 前缀
2. **src/utils/request.js** — token 头从 `X-Token` 改为 `Authorization: Bearer`，超时从 5s 改为 10s，响应拦截器适配 `{code:200, message, data}` 格式，增加 401 过期处理
3. **src/api/user.js** — 统一三个接口路径：login → `/user/login`，getInfo → `/user/info`，logout → `/user/logout`；getInfo 不再传 token 参数（通过 Authorization 头传递）
4. **src/store/modules/user.js** — 适配后端字段：name 兼容 `name/username/nickname`，avatar 有默认值，新增 roles 状态
5. **src/store/getters.js** — 新增 `roles` getter
6. **src/utils/validate.js** — `validUsername` 从写死 admin/editor 改为只校验非空
7. **src/views/login/index.vue** — 文案改中文，默认值清空，标题改为"图书管理系统"
8. **src/settings.js** — title 改为"图书管理系统"

### 后端需要提供的接口约定
- `POST /user/login` — 入参 `{username, password}`，返回 `{code:200, data:{token:"jwt-xxx"}}`
- `GET /user/info` — 通过 Authorization 头获取 token，返回 `{code:200, data:{name, avatar, roles}}`
- `POST /user/logout` — 返回 `{code:200, data:"success"}`

### 注意事项
- 后端端口默认假设 8080，如不同需改 vue.config.js 的 proxy.target
- 后端响应格式假设 `{code:200, message, data}`，如不同需改 request.js 响应拦截器
- JWT 传递方式假设 `Authorization: Bearer <token>`，如不同需改 request.js 请求拦截器
